# MagicSquare_1004 — Mom Test 채점 프롬프트

## 사용 프롬프트

```
아래 Mom Test 결과를 채점해줘. 수정하지 마.
[워크북 전체]

체크:
- [ ] 미래 가정("~하면 좋겠다") 없음
- [ ] 과거 행동·시간·실수 구체성 있음
- [ ] 진짜 문제에 솔루션名(TDD/PyQt/Cursor) 없음
- [ ] 표면 문제와 진짜 문제가 분리됨
- [ ] MagicSquare 도메인(4×4, 10선, 34, 빈칸 2개) 반영

점수 /10 + 고칠 질문 1개만 제안
```

---

## 채점 기준

| # | 항목 | Pass 기준 |
|---|------|-----------|
| 1 | 미래 가정 없음 | 진짜 문제·증거가 과거형. "~하면 좋겠다" 없음 |
| 2 | 구체성 | 시간(분), 실수 종류, 행동 순서가 있음 |
| 3 | 솔루션名 없음 | TDD/PyQt/Cursor/프로그램명이 진짜 문제에 없음 |
| 4 | 분리 | 표면=솔루션, 진짜=불편·비용·판정 |
| 5 | 도메인 | 4×4, 합 34, 10선, 빈칸 2개 반영 |

## 출력 형식

```
## 체크리스트 (✅ / △ / ❌)
## 점수: N / 10
## 고칠 질문 1개: [추가 인터뷰용 질문]
```

## 참고 — 현재 워크북 기준 채점 (7/10)

- 강점: Mom Test 핵심 준수, 표면/진짜 분리
- 감점: Q2 미응답, 도메인 숫자(34, 10선) 미명시
- 고칠 질문: "20분 날린 그 과정에서, 대각선 하나를 빼먹었다는 걸 언제 처음 알았어?"
