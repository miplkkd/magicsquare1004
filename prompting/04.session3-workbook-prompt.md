```
Mom Test 결과:

- 진짜 문제 (한 문장): [여기에 붙여넣기]
- Mom Test 증거 3줄: [여기에 붙여넣기]

MagicSquare_1004 세션 3 워크북을 채워줘:
1) 주제 한 문장 (Mom Test 기반, 솔루션 최소화)

3) 성공 기준 3개 (Mom Test 증거와 연결)
```

## 산출물 템플릿

### 1) 주제 한 문장

> 4×4 부분 마방진에서 행·열·대각선(합 34)을 빠짐없이 검증하지 못해, 틀린 배치를 늦게 알게 되는 문제를 줄인다.

### 2) R-G-I-O

| | 내용 |
|---|------|
| **Role** | 4×4 부분 마방진을 풀고 맞는지 확인하는 학습자 |
| **Goal** | 10조건 중 하나라도 틀리면 즉시 알 수 있다 |
| **Input** | 4×4 격자 (1~16, 빈칸 0×2) |
| **Output** | 통과/실패 + 위반 조건 |

### 3) 성공 기준 3개

1. 10조건 한 번에 검사, 대각선 1개 누락 시 실패
2. 행·열만 맞고 대각선 틀려도 통과 불가
3. 실패 시 깨진 줄/대각선 명시

### 4) 표면 문제 — 하지 않을 것

- 체커 앱/GUI, Solver, TDD 설교, GridUI, 기능 확장

### 5) 8계층 (이번 세션)

- Rule / Command / (Skill) / Test Loop
