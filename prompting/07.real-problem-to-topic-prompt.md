# MagicSquare_1004 — 진짜 문제 → 주제 선정 (설명 요청)

## 사용 프롬프트

```
이렇게 하면 진짜문제 한문장이 나오고 그걸로 주제선정하라는데 알려줘
```

---

## 기대 답변 구조

1. **4단계 흐름:** Mom Test 질문 → 과거 사실 → 진짜 문제 한 문장 → 주제 선정
2. **진짜 문제 공식:** `[상황] + [행동/누락] + [손해]` (솔루션名 없음)
3. **주제 선정:** 진짜 문제 키워드에서 ECB·8계층 우선순위 도출
4. **표면 문제:** "~~프로그램 만든다" → 나중에만, 주제 아님

---

## MagicSquare_1004 적용 예

```
진짜 문제: 여러 조건 맞추다 하나 놓치면 20분 날린다
     ↓
주제: 「행·열·대각선 합 34 검증 누락 방지」
     ↓
1순위: SquareValidator / Rule / Test Loop
     ↓
나중: Solver, GridUI
```
