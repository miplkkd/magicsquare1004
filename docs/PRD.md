## 1. 개요

### 1.1 제품명

MagicSquare_1004 — 4×4 부분 마방진 검증 도구

### 1.2 한 줄 설명

4×4 부분 마방진(빈칸 2개, 합 34)의 **행·열·대각선 10조건**을 빠짐없이 검증하여, 학습자가 틀린 배치를 늦게 알게 되는 문제를 줄인다.

### 1.3 배경 (Mom Test)

| 항목 | 내용 |
|------|------|
| 페르소나 | 4×4 격자, 빈칸 2개(0), 1~16, 합 34 맞추는 학습자 |
| 진짜 문제 | 여러 조건을 맞추다 하나를 놓치면, 틀린 답을 오래 붙잡다 20분을 날린다 |
| 핵심 증거 | 지난주 OO 과제, 대각선 하나 빼먹음, 20분 낭비 |

## 2. 목표

### 2.1 제품 목표

- 행·열·대각선 **10조건**을 한 번에 검사한다
- 대각선 1개만 검증에서 빠져도 **실패**로 판정한다
- 실패 시 **어느 조건**이 깨졌는지 즉시 알려 준다

## 4. 기능 요구사항

### 4.1 FR-001: 격자 입력

- 4×4 정수 배열을 입력받는다
- 값: 0(빈칸) 또는 1~16
- 빈칸(0)은 정확히 2개

### 4.2 FR-002: 10선 합 검증

- **행 4개**, **열 4개**, **대각선 2개** — 총 10조건
- 각 선의 합이 **34**인지 검사
- 하나라도 ≠ 34이면 **실패**

### 4.3 FR-003: 숫자 규칙 검증

- 1~16 각 숫자는 최대 1회 (0 제외)
- 범위 밖 숫자는 실패

### 4.4 FR-004: 판정 출력

- **통과:** 10조건 + 숫자 규칙 모두 만족
- **실패:** 위반 조건 목록 (예: `row 2 sum=32`, `diag ↙ sum=30`)

### 4.5 FR-005: validate 명령 (Command)

- CLI 또는 함수 호출: `validate(grid)` → `{ ok: bool, violations: [...] }`
- Rule 계층과 1:1 대응

## 6. 성공 기준 (Acceptance Criteria)

| # | 기준 | Mom Test 연결 |
|---|------|---------------|
| AC-1 | 대각선 1개만 검증 누락 시나리오 테스트 → **실패** | "대각선 하나를 빼먹어" |
| AC-2 | 행·열만 34, 대각선 틀림 → **실패** (통과 불가) | "20분 날렸다" |
| AC-3 | 실패 출력에 **위반 선(행/열/대각선)** 명시 | OO 과제 재확인 비용 절감 |
| AC-4 | 10조건 + 숫자 규칙 전부 통과 → **성공** | 완성 마방진 판정 |

---

## 7. 실패 조건 (Failure Conditions)

1. 대각선 ↘ 또는 ↙ 합 ≠ 34
2. 행 또는 열 합 ≠ 34
3. 0(빈칸) ≠ 2개
4. 1~16 중복 또는 범위 밖
5. 행·열만 맞고 대각선 틀림 → "완성" 오판
